# 개인화 전통주 정보·추천 웹 서비스

광주인공지능사관학교 4기 클라우드반 1차 팀 프로젝트입니다.

## 프로젝트 목적

전통주의 맛·도수·가격·주종·보관 정보 등을 제공하고, 사용자의 취향 입력과 설문 데이터를 활용해 개인화된 전통주를 추천하는 Flask 웹 서비스를 구현했습니다.

## 주요 데이터

- 한국농수산식품유통공사 전통주·양조장 데이터
- Selenium 기반 술담화 웹 정보 수집
- Google Form 및 대면 설문 취향 데이터

## 추천 방식

### 실험 단계

설문 취향 데이터를 정규화하고 `KNeighborsClassifier(n_neighbors=3)`로 분류 실험을 수행했습니다. 당시 프로젝트 결과 기록 기준 정확도는 85%입니다. 이 수치는 최종 웹 서비스 전체의 추천 정확도가 아니라 KNN 분류 실험 결과입니다.

### 최종 서비스

최종 Flask 서비스는 코사인 유사도를 사용합니다.

1. 성별·연령대·주종으로 설문 데이터를 필터링
2. 사용자 입력과 설문 응답 간 코사인 유사도로 사용자 기반 추천 계산
3. 사용자 입력과 전통주 맛·도수·가격 특성 간 코사인 유사도로 아이템 기반 추천 계산
4. 사용자 기반 2개와 아이템 기반 2개를 결합해 최대 4개 추천 결과 반환

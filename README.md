# Idle_cloud
광주인공지능사관학교 클라우드반 1차 프로젝트

## 프로젝트 정리

전통주 정보 제공과 사용자 취향 기반 추천을 결합한 팀 프로젝트입니다.

- 개인 직접 기여: Selenium/BeautifulSoup 기반 데이터 수집·정제, 양조장 데이터 정리, 2차 설문 전처리, NearestNeighbors 기반 전통주 매칭
- 팀 결과: KNN 분류 실험 당시 기록 정확도 85%
- 해석 주의: 85%는 최종 추천 웹서비스 전체 정확도나 개인 단독 성과가 아닙니다.
- 현재 main은 역사적 제출 코드로 보존하며 2026 기준 완전 재현 가능성을 주장하지 않습니다.
